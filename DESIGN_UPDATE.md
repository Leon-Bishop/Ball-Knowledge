# Ball Knowledge v3.2 design update

- Removed the football emoji quiz descriptor from the hero header in every language.
- Dark mode league logos now sit on a neutral white backing for consistent contrast, without altering the original logos.
- Dark-mode selected league tiles use a readable purple surface.
- Existing finite-round gameplay, translations, and trivia data are unchanged.

## Updating GitHub Pages
Replace your repository files with this package and commit to `main`. Keep Settings → Pages → Source: GitHub Actions. The included workflow builds and deploys the site.
